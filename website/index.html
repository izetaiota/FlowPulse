Core Features

四大核心价值

把分散在各平台后台的琐事收进一个工作台，省下切换与搬运的时间。

01

统一消息看板，不用来回切换后台

聚合抖音、小红书、公众号、视频号私信、评论、@提醒，在同一个面板查看、筛选、直接回复。消息标签、关键词预警、历史存档，轻松维护粉丝互动。

02

选题 + 素材库，沉淀你的内容资产

选题日历排期、灵感随手记录、选题状态流转；素材库支持图片 / 视频 / 文案 / 封面分类打标、检索、版本管理。所有素材集中存放、反复复用，告别散落在网盘和聊天记录里的文件。

03

一次创作，全域智能分发

一份原稿，自动适配各平台格式规范，支持定时发布、批量分发、任务队列管理。发布失败自动日志记录，快速定位驳回、风控、授权异常问题。

04

内容 + 投流一体化数据闭环

不止看点赞收藏，同时对接千川、薯条、视频号推广。投放计划、消耗、转化、成交、ROI 自动汇总，把内容效果和投放效果绑定复盘，不用在多个广告后台来回对比。

Deployment

两种产品模式，随你选择

想开箱即用选 SaaS，在意数据归属选私有化部署。

私有化 Docker 部署

V1 重点

数据完全自留，本地部署，素材、粉丝消息不经过第三方服务器。

  • Docker 一键部署，提供 compose 配置
  • SQLite 单文件数据库，无需复杂中间件
  • 素材存本地磁盘，容量自己说了算

云端 SaaS

规划中

开箱即用，注册即上手，不需要任何运维知识。

  • 免部署、免维护，打开浏览器即用
  • 自动升级，新功能第一时间可用
  • 适合不想折腾环境的创作者

FAQ

常见问题

支持哪些平台？+

首期支持微信公众号、抖音、小红书、微信视频号，后续持续扩展。

私有化部署难度高吗？+

Docker 一键部署，提供 compose 配置，SQLite 单文件数据库，无需复杂中间件。

接口是官方开放 API 吗？风控怎么样？+

优先使用平台官方 OAuth 开放接口；接口能力不足时提供兜底兼容方案，同时内置风控提醒机制。

可以对接飞书 / 钉钉通知吗？+

支持 Webhook 推送日报、告警、新消息提醒到飞书、钉钉。
